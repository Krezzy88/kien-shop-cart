# Security policy

This repository is a learning and portfolio demo. To report a security issue, do not open a public issue with exploit details; contact the repository owner privately through GitHub. Include the affected commit, impact, and a minimal reproduction, and allow time for a fix before public disclosure.

The demo has no authentication, uses a fixed sample cart, and is not intended for real customer data or production use. Security reports are welcome, but hardening the business application and operating production infrastructure are outside the current project scope.
